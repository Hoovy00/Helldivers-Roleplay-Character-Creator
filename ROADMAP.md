# Helldivers Roleplay Toolkit

## North star

A small, approachable roleplaying app inspired by the Helldivers 2 setting and Pathfinder 2e rules. The long-term dream is to create and run complete Discord-based sessions from one place: build characters, enemies, equipment, encounters, and maps, then use them together at the table.

This project should grow in useful slices. Each step should leave us with something playable, rather than requiring the whole dream to arrive at once.

## Product principles

- Keep the rules and play experience simple enough for casual roleplay.
- Make the setting feel like Helldivers: dangerous missions, desperate teamwork, and over-the-top managed democracy.
- Treat Pathfinder 2e as a rules foundation, adapting only what the game needs.
- Prefer clear, editable content over hidden magic; make homebrew easy to add.
- Design Discord play as a key destination, while keeping the first prototype easy to run and learn.

## Roadmap (draft)

### 0. Agree on the first playable slice

- Choose the first play mode: lightweight narrative checks, a compact PF2e-inspired combat loop, or a small blend.
- Define a short mission that demonstrates the desired play: briefing, deployment, objective, complication, extraction.
- Decide how closely to track PF2e details such as actions, proficiency, conditions, and equipment.
- Write down the minimum character and enemy information needed to play that mission.

**Deliverable:** a one-page rules sketch and a tiny sample mission that can be played manually.

### 1. Build a local playable prototype

- Create and save a character with a small set of stats, skills, and loadout.
- Support a basic check and a turn-based encounter with a few recognizable PF2e concepts.
- Add a small set of enemies, weapons, stratagem-like abilities, and conditions.
- Run a mission from a simple session screen or command-line interface.

**Deliverable:** one complete mission can be played locally from start to finish.

### 2. Make content authorable and reusable

- Add create/edit flows for characters, enemies, items, encounters, and maps.
- Store content in a format that is easy to inspect, back up, and extend.
- Add encounter assembly and mission templates.
- Keep rules data separate from application code so balance and homebrew changes are manageable.

**Deliverable:** a GM can prepare and run multiple distinct missions without editing program code.

### 3. Add Discord session play

- Choose a Discord integration approach and define how a session is started, joined, and controlled.
- Add player-facing commands or interactions for checks, actions, inventory, and status.
- Give the GM tools for narration, enemy turns, encounter state, and mission pacing.
- Make session state resilient to disconnects and bot restarts.

**Deliverable:** a GM can run a complete mission for a group in Discord.

### 4. Grow the campaign toolkit

- Improve map support, exploration, mission generation, and campaign records.
- Expand content libraries and homebrew authoring.
- Add quality-of-life features based on actual play feedback.

**Deliverable:** the toolkit supports ongoing campaigns, not just one-shot missions.

## Initial scope guardrails

- Start with one mission and a deliberately small rules subset.
- Use original text and homebrew presentation; treat Helldivers 2 and PF2e as inspirations/reference systems, not a reason to reproduce their books or assets wholesale.
- Keep the design modular so a local prototype can later gain a Discord interface without throwing away its game logic.

## Working notes

- This document is the shared roadmap for this chat. Update the decisions, current milestone, and next concrete step as the project takes shape.
- Current status: first local character-builder slice is available in `index.html`.
- Current milestone: a player can enter a character name and level, assign ability modifiers and proficiency ranks with circle buttons, and see all six abilities, three saves, and fourteen standard skills in fixed alphabetical order. Custom Lore skills can be added, removed, and rated; they use Intelligence and sort in with the skills.
- Ability modifiers are fixed: Weak −1, Untrained +0, Trained +1, Expert +2, Master +3, Legendary +4. A skill or save total adds its linked ability modifier to proficiency: untrained +0; trained level +2; expert level +4; master level +6; legendary level +8. Fortitude links to Constitution, Reflex to Dexterity, and Will to Wisdom. Legendary is available at level 9 and above. This is a lightweight house rule; the app does not otherwise enforce rank caps.
- Characters save in browser storage on the current device as a roster: a Character bar at the top switches between them and has New, Duplicate, Import JSON and Delete (with a confirmation). Import accepts files made by Export JSON (several at once, or a list of characters) and checks each one; older saves load cleanly. The single character saved before the roster existed is moved in automatically, and that old save is left in place as a backup. Each character can be printed or exported as JSON.
- Armor and weapon proficiency controls sit directly above Inventory / Loadout. Each category (Unarmored Defense, Light Armor, Medium Armor, Heavy Armor; Unarmed, Simple, Martial, Advanced) has its own Untrained, Trained, Expert, or Master selection, saved with the record and included in JSON export. A short definition under each category name includes illustrative Helldivers gear examples where helpful.
- Inventory / Loadout provides alphabetical dropdown catalogs for body armor, primary and secondary weapons, melee weapons, throwables, boosters, and four Stratagem slots. Each dropdown includes Custom with a text entry; Misc. remains free text. Entries save with the character and export to JSON. Selecting a catalog item (including boosters) opens a collapsible stats panel with its armory description, key stats, and a link to the wiki article. Armor details show Armor Type, Armor, Speed, Stamina, Passive and the passive's description, followed by body-location and explosive damage multipliers calculated from the armor rating. Penetration is shown as Light, Medium, Heavy, or Anti-Tank 1–6 with the AP value.
- Item stats are bundled in `data/item-stats.js` (generated from the Helldivers Wiki by `tools/build_item_stats.py`; run `py tools/build_item_stats.py` after game updates). The wiki blocks live browser requests, so the app no longer fetches anything online. GM house rules go in `data/item-overrides.js`, which is merged over the wiki values and is never overwritten by the script.
- Weapons, throwables and stratagems with more than a single base shot have a "Special effects & extra damage" tab inside their stats panel: status effects (e.g. Coyote's Fire), impact explosions and delayed detonations (e.g. Ultimatum, 500kg), shrapnel, lingering clouds and alternate ammo or fire modes. It is generated from the wiki's detailed attack data and keeps damage, penetration, radius, duration and status; physics and force values are left out.
- Booster panels show the in-game text plus the real effect numbers from the wiki (e.g. Vitality Enhancement: −10% damage taken). Booster pages keep those numbers in prose, so they are summarized by hand in `BOOSTER_EFFECTS` in `tools/build_item_stats.py`; the script warns when a new booster has no summary yet.
- Stratagem slots list only stratagems a Helldiver can bring (Offensive, Supply and Defensive permits), grouped by permit and using full wiki names (e.g. "AC-8 Autocannon"). The list is built from the wiki, so new stratagems appear after re-running the build script. Mission stratagems (Reinforce, Resupply, SoS Beacon, drills, Hellbomb, etc.) are excluded; characters saved with an excluded or renamed stratagem keep it, either mapped to its new name or as a Custom entry. The dropdown catalog includes the Scope of Authority Warbond and its SS-500 Pale Prosecutor Superstore armor release from October 20, 2026.
- Enemies page (enemies.html, "Enemies" tab in the header of both pages; shared styling now lives in styles.css): a library of 83 wiki enemies (Terminids, Automatons, Illuminate) with search and faction filter, plus Custom enemy. Each stat block has name, faction, level, threat, body armor, max HP and explosive resistance; AC, Attack, Fort, Ref, Will, Perception and Ability DC calculated by house rule (Moderate: AC 15 + level adjusted by armor, Attack level + 6, saves/Perception level + 4, DC level + 15; High +2, Low −2; starting level = minimum difficulty − 1), each overridable by typing a number; a current-HP tracker with Damage/Heal; editable attacks in game damage numbers with the attack bonus; the wiki anatomy table (part HP, armor value, fatal); and notes. Duplicate, Remove, Restore all HP, Clear encounter and Print. Armor values (AV) use the same scale as weapon penetration (AP). Enemy data is in data/enemy-stats.js (`py tools/build_item_stats.py --enemies` refreshes it; a full run does too). The encounter is saved on the device, and the page uses the open character's theme.
- Vehicles: vehicle stratagems (Exosuits, FRVs, Bastion, Maelstrom) carry wiki data: hull HP and armor from the attack data, explosive resistance from the Anatomy table, and each weapon mount with its damage, penetration, blast and capacity (plus stomps and destruction explosions). This shows in their stratagem panels. The Vehicle section sits directly under the health bars in Combat Overview; its picker offers every Super Earth vehicle that can be called in by stratagem (Exosuits, FRVs, Bastion, Maelstrom), whether or not it is in the diver's stratagem slots, plus Custom vehicle (name, hull HP, notes). The section has: hull HP bar, Damage hull (Standard or Explosive, applying the vehicle's explosive resistance), Repair fully, and each mount's attack modifier (Dexterity + Advanced, conditions applied). The vehicle appears on the Discord card and the squad view.
- Vehicle ammo: each weapon mount tracks ammo from the wiki data, with Fire (one action's worth: controlled bursts for machine guns, e.g. Exosuit HMG 20 rounds; one shot for cannons, missiles and rockets) and −/+ on every count. Mounts with spare mags reload from them (Gunner FRV HMG 100 + 4 spares); single-shell main guns with no shell count on the wiki reload freely (Bastion, Maelstrom); other mounts are one belt or pod that runs down (Exosuit HMG 1350, rockets 14; Bastion MG 2000). Rearm vehicle refills every mount; picking a different vehicle starts with full ammo. Custom vehicles can set one weapon's ammo pool.
- Fully upgraded Super Destroyer for every character (wiki "Ship Modules"): stratagem cooldown, call-in, Eagle uses and rearm use the wiki's fully upgraded values (85 of 97 stratagems list them; the rest use the module rules: Eagles −50%, Orbitals/Support/Backpack/Sentry/Emplacement −10%, Orbital call-in −1 s, Eagle +1 use and −20% rearm), plus Morale Augmentation −5% on every cooldown (the wiki's upgraded values leave it out). Support weapons arrive with every spare magazine (Donation Access License) and supply boxes refill them completely (Superior Packing Methodology). Stratagem cards show the base cooldown next to the upgraded one.
- Weapon customization: primary and secondary weapons have a Customize panel with the Optics, Muzzle, Underbarrel and Magazine attachments the wiki lists for that weapon (58 weapons; data/attachments.js, refreshed with `py tools/build_item_stats.py --attachments` or a full run). The magazine choice sets capacity, spare and starting magazines in the ammo tracker (e.g. Liberator Short 30 + 16, Extended 45 + 8 default, Drum 60 + 6); other attachments list their recoil, spread, sway, ergonomics and zoom effects for reference. Attachments save with the character, appear on the Discord card, and reset when the weapon changes.
- Attachment attack bonuses (house rule, `attachmentRules()` in index.html): derived from each attachment's game stats as PF2e circumstance bonuses/penalties by range band (Close ≤ 80 ft, Medium 85–245 ft, Long 250 ft +; converted from 25 m / 75 m to 5-ft steps). Recoil reduction totalling 30%+ → +1 to burst fire (weapons firing more than 1 round per action); recoil increase 20%+ → −1 to burst fire. Sway +20%+ → −1 Long; sway −15% or better → +1 Long. Optics: 8x+ → +1 Long, −1 Close; 3x+ → +1 Medium & Long; 2x → +1 Medium; reflex/holo/red dot → +1 Close. Spread reduction 80%+ → +1 Medium & Long, 40%+ → +1 Medium; horizontal spread +50% (Duckbill) → +1 Close. Laser sight → +1 Close. Flashlight → ignore darkness concealment (note only). Per band only the best bonus and worst penalty apply, and an attachment penalty doesn't stack with a condition's circumstance penalty (Prone). Attack cards show a Close/Medium/Long strip; the Customize panel shows each attachment's table effect.
- Encounter builder upgrade (enemies.html): library "How many to add" (auto-numbered names: Charger, Charger 2…); PF2e encounter-budget difficulty panel (party level and size, defaults from the squad; XP by level difference, High/Low threat = ±1 level like elite/weak; downed enemies excluded); initiative tracker (divers from the builder's squad summary with their sheet initiative, enemies with Perception, rolls typed in, Sort with enemies first on ties, Next/Previous turn skipping downed enemies, round counter, quick damage per enemy, notes for divers, add divers/allies by hand, new enemies join the order automatically); optional "count squad stratagem cooldowns down each round" — writes `helldivers-field-record-v1-pending-rounds`, which the builder applies on load or via the storage event; compact one-line enemy cards (Compact all); per-enemy conditions and XP worth; to-hit numbers for each enemy against every squad member's AC; saved encounters (`-encounters`, save/load/delete by name). The builder writes `helldivers-field-record-v1-squad-summary` (name, level, AC, initiative, Perception, HP, speed for every character) on every save and on load.
- Enemy hit locations (enemies.html, `applyHit()` / `partList()`): each enemy card has a hit form — where it hits (Body = the enemy's body armor straight to Main, or any anatomy part with AV, HP and % to Main; "which one" for parts with several copies), weapon preset (each squad member's kit first, from the squad summary's `weapons`, then every weapon with Damage + Penetration stats, split per attack: e.g. Autocannon APHET 325 AP 4 / Explosion 150 / Flak 110 AP 3), damage, AP 0–10, Standard/Explosive, number of hits. Rules from the wiki Damage page: AP > AV full damage, AP = AV 65%, AP < AV ricochet; part takes the damage and passes % to Main capped at the part's full HP; "Main" parts only damage Main; destroying a fatal part kills; explosive damage reduced by the enemy's explosive resistance (simplification: the wiki has per-part ExDR, the data only has the enemy's). Part HP tracked per copy (`enemy.parts`), shown in the Anatomy table (destroyed parts struck through); live preview before applying; last-hit log; Heal Main / Restore all. Verified against the wiki example (Liberator on Devastator arm: 170 arm, 705 Main). Compact cards and tracker quick damage still go straight to Main.
- Enemies hit back + mission tracker + re-levelled enemies:
  - GM action queue: the Enemies page writes actions to `helldivers-field-record-v1-gm-actions`; the builder applies them on load or via the storage event (`applyGmActions()`), then writes results to `-gm-log` (shown as the Combat log on the Enemies page). Actions: `damage` (charId, location, damageType, amount, source) through the shared `takeDamage()` (armor rating, passives, boosters, limb breaks, Lucky/defib rolls), `reinforce` (full HP, healthy limbs, redeploy loadout without the support weapon, clears dying/unconscious/wounded/doomed), `newMission` (every character: stratagems reset, full HP, fresh loadout, defib recharged, vehicle reset).
  - Enemy attacks: ⚔ on each attack row opens a form — target diver (from the squad summary), body part, damage type (guessed from the attack name/type), damage, critical ×2 — with the d20 roll needed against that diver's AC.
  - Mission panel (Enemies page, `-mission`): name, game difficulty, length, status; mission clock (−6 s per initiative-tracker round, ±1 min buttons); reinforcement pool (5 per diver, Reinforce a chosen diver); common/rare/super samples; objectives checklist; Start new mission (resets the panel, keeps name/length/objectives unticked, queues `newMission`).
  - Enemy levels follow the level guide: `data/enemy-levels.js` (GM-editable; fallback min difficulty − 1). 0–1 fodder, 2–3 veterans/elites, 4–5 specialists, 6–8 heroic monsters (Charger 6, Hulks 6–7, Impaler/tanks/War Strider 8), 9 Bile Titan/Dragonroach, 10 Factory Strider/Vox Engine, 11 Leviathan, 12 Hive Lord/Overship. Saved enemies still on their old default level move to the new one (`levelV2`).
- Vehicle levels (`VEHICLE_LEVELS`, `vehicleLevel()`, `vehicleFireControl()` in index.html): same scale as enemy levels — FRVs 4, Exosuits 6, Maelstrom/Bastion 8; custom vehicles have a level box (default 4); per-item override `vehicleLevel` in data/item-overrides.js. Fire control is a PF2e item bonus to every mount's attack: ⌊level ÷ 3⌋, max +3 (FRV +1, Exosuit +2, tank +2, level 9+ +3). Shown on the vehicle card, in the attack breakdown and on the printed sheet.
- Printable sheet: printing (button or Ctrl+P) hides the app and prints a separate two-page sheet built by `printSheetHtml()` on `beforeprint` into `#printSheet` (styles under "Printable character sheet" in styles.css). Page 1: header with Player/Mission write-ins, AC/Speed/Initiative/Perception/saves, abilities, skills, proficiencies, health table with Current write-ins and Injured/Broken boxes, stim/dying/wounded/doomed circles, conditions lines, armor & booster rules. Page 2: attack cards (modifier, range, attachment bands, ammo write-ins and spare-mag boxes, Unarmed inside Melee), stratagem table with use boxes and "ready on round", vehicle hull/mount write-ins, gear and note lines. Black and white friendly.
- Phone layout: sticky jump bar (all widths) to each section, Attacks and Stratagems (opens minimized sections first); at ≤560 px the level guide starts closed, toolbar/roster buttons go to grids, the AC/Speed/Initiative cards show just the number (tap for the breakdown), numbers come before the diver picture, range notes and table ability columns are hidden, inputs use 16 px text (no zoom on focus). Touch screens get bigger +/−, rank and minimize buttons.
- Collapsible sections: every numbered section plus the Status effects, Attacks and Stratagems panels have a −/+ minimize button (`setupCollapsibles()` at the end of the script). Open/closed state is per browser (localStorage `helldivers-field-record-v1-collapsed`), not saved with the character; printing shows everything. Unarmed attacks render inside the Melee card.
- Range increments (house rule, `RANGE_BY_TYPE` / `RANGE_EXCEPTIONS` / `rangeProfile()` in index.html): PF2e style, −2 per increment beyond the first, max 6 increments. By type: AR 100 ft, SMG 60, shotgun 30, marksman 200, sniper 300, energy 100, pistol 50, anti-materiel/railgun 300, anti-tank 150, heavy energy 150, heavy weapons 120, missiles 200, rocket 150. Exceptions include Slugger 80, lasers 120, plasma 80, Eruptor 150, revolvers 60, Quasar 200, Autocannon 150, grenade launchers 80, Spear 300; flamethrowers/Meltagun fixed 30 ft and Blitzer fixed 60 ft (no penalty, hard max). C4 and the Breaching Hammer have none. Laser weapons (LAS- prefix except Trident and Quasar) are line of sight: no range penalty and no maximum range (instant beam, no drop or drift); attachment optic bonuses still apply. Per-item override: `rangeIncrement`, `rangeFixed` or `rangeUnlimited` (true/false) in data/item-overrides.js. Attack cards show each increment's penalty and the resulting modifier.
- Vehicle ammo counts that only appear in a vehicle's wiki Tactical Information are applied by the build script (VEHICLE_AMMO_FIXES, each with a note shown on the mount): Bastion 120mm cannon 31 shells (1 loaded + 30 spare, reloads use a shell) and coaxial HMG 2,000; Maelstrom rotary guns 7 belts of 300 (early reloads discard the rest of the belt) and missile pods 20; Supply FRV turret ~120 rounds reloaded from the vehicle's 8 supply charges, which also resupply a diver (Resupply diver button); Incinerator FRV 800 fuel with no reload; Emancipator, Lumberer and Gunner FRV notes. A mount whose ammo setup changes after a data update starts fresh (fired counts kept). Re-check VEHICLE_AMMO_FIXES when vehicles are rebalanced.
- Every ammo tracker (guns, support weapons, throwables, vehicle mounts) shows total ammo carried against the maximum (magazine + all spares, in rounds; e.g. Liberator 315 / 405 after deploying) and the rounds fired, thrown or heat used, with a reset button. The count survives Reload, Full refill, Rearm and Redeploy, and resets on New mission (single or squad-wide). Tank main guns show "Unlimited shells".
- GM squad view (Squad view button on the Character bar): one card per saved character with level and armor weight, Main HP bar and Deceased, broken or injured limbs, AC, Speed, Initiative and Perception (conditions applied), active conditions, stims and ammo (guns, called-in support weapons, throwables), and each stratagem's status. The open character is highlighted; Open switches the sheet to another character. Next round (all), +1 minute (all) and New mission (all) tick or reset every character's stratagems at once. The open/closed state is remembered on the device.
- Copy for Discord (toolbar): copies a barebones loadout card in Discord markdown: name and level, armor (with type and passive), primary, secondary, melee, throwable, booster, stratagems and other gear. Empty slots are left out and custom items use their typed names. If the browser blocks the clipboard, a small window shows the text selected for manual copying.
- Speed (Combat Overview card): the armor's in-game Speed (medium 500 = 100%; armor without a listed speed uses the wiki formula 600 − armor rating) scaled to PF2e's 25 ft Stride per action: 25 × speed ÷ 500, rounded to the nearest 5 ft with exact halves rounding away from 25. Light 550 → 30 ft, medium 500 → 25 ft, heavy 450 → 20 ft, unarmored 600 → 30 ft. Oxygenator +10% and Experimental Infusion +10% while a stim is active apply to the in-game speed first. Broken legs −10 ft, Encumbered −10 ft (minimum 5 ft); Prone = Crawl 5 ft; Immobilized, Grabbed, Restrained, Paralyzed, Petrified, Unconscious and Dying = 0 ft. The breakdown shows every step, and Speed is in the JSON export.
- Perception (Wisdom + its own Untrained–Legendary rank) leads the "Perception & saving throws" table. Initiative sits beside AC in Combat Overview: it rolls with Perception by default, or any skill or Lore the GM calls for ("Rolls with" picker, saved per character), with a breakdown. Condition penalties apply: Fascinated −2, Blinded −4 and Unconscious/Dying −4 to Perception; Deafened −2 only to Perception rolled for initiative; plus Frightened, Sickened and Stupefied as usual. Perception and Initiative are included in JSON export.
- Ammo, throwables and stims are tracked per character. Numbers come from the wiki's weapon data (magazine, spare mags or rounds, starting amounts, supply-box amounts, throwable max/start); stims follow the wiki (drop with 2, carry 4, resupply gives 2). Primary/secondary cards have Fire (uses a set number of rounds per action ≈ 2 s: about half of what full-auto guns fire in 2 s, up to 3 aimed shots for semi/pump/bolt guns, one burst for burst guns, a fifth of the tank for flamers; overridable with shotsPerAction) and Reload (a magazine swap discards the old magazine's rounds; round-fed guns top up). Lasers track heat (one per action, about 2 s of fire each) and heat sinks; the Blitzer needs no ammo. Throwables have Throw. The Stim button uses one of the diver's stims (or a squadmate's when out). A Pick up row follows the wiki's Supplies page: Supply box (each item's supply amount + 2 stims), Ammo box (each gun's ammo-box amount, no stims or grenades), Grenade case (throwables full), Stim crate (stims full), Full refill (everything to maximum, magazines included) and Redeploy (starting amounts). Every count has −/+ for GM adjustments. Applied passives: Med-Kit +2 stims, Engineering Kit / Grenadier / Integrated Explosives +2 throwables, Siege-Ready +20% spare ammo (rounded up, not the Ultimatum), Hellpod Space Optimization deploys fully stocked.
- Support weapons in stratagem slots get their own attack card: Dexterity + Advanced proficiency (melee support tools such as the Breaching Hammer use Strength + Martial; overridable with weaponCategory). Ammo appears when the stratagem is called in (fresh pod with the wiki's starting ammo; calling again replaces it) and is dropped on Redeploy, as in the game. Types: magazines/rounds (MG-43, Railgun, Recoilless…), one belt or tank with no reload (Maxigun, Belt-Fed GL, Cremator: pickups top it up), disposables (EAT pods hold 2 launchers; Commando and Bullet Storm are one), Laser Cannon heat + heat sinks, and no ammo (Arc Thrower, Quasar, Nova, Flag, Defoliation Tool). C4 Pack and Solo Silo are tracked by hand. Supply and ammo boxes and Full refill include called-in support weapons; Siege-Ready applies except to backpack weapons. Rocket, missile, anti-tank and charge-up weapons fire once per action.
- Stratagem tracker (Combat Overview): one card per loadout slot with status (Ready, Cooldown, Inbound, Rearming, out of uses), the input code, uses and timings, Call in and a GM "Ready now". Game seconds become 6-second rounds, rounded up (e.g. support weapons 480 s = 80 rounds, sentries 90–180 s = 15–30, Eagles 15 s = 3, call-in 7.75 s = 2). Next round and +1 minute (10 rounds) count everything down. Eagles have uses per rearm; Eagle Rearm (150 s = 25 rounds) locks all Eagles and then refills them. Orbital Laser (3) and Exosuits (3, per the wiki change history) have uses per mission. New mission resets everything. 10 + Dexterity (up to the armor's Dex cap) + proficiency in the equipped armor's category + the category's item bonus. House-rule table (PF2e-style, every armor tops out at +5 from item + Dex): Unarmored +0 / no cap; Light +1 / cap +4; Medium +3 / cap +2; Heavy +5 / cap +0. The armor category comes from the wiki armor type; the Armor dropdown has an "Unarmored" option, and Custom armor gets an armor-type picker. A breakdown of every part is listed under the AC number, and armor stat panels show the table AC bonus and Dex cap. The numbers live in `armorCategories` in index.html.
- Attack modifiers are calculated automatically for Primary, Secondary, Melee, Throwable and Unarmed: ability (Dexterity for guns and throwables, Strength for melee and unarmed) + proficiency in the weapon's category. Categories follow the wiki weapon type (`weaponTypeCategories` in index.html): Simple = assault rifles, SMGs, pistols, standard grenades; Martial = shotguns, marksman rifles, energy weapons, melee, special throwables; Advanced = explosives and special primaries/secondaries. A single weapon can be moved with `weaponCategory` in data/item-overrides.js; custom weapons get a category picker. Each attack card lists its breakdown, and weapon stat panels show the table category.
- Armor passives and boosters are applied to health and damage. The damage form has a damage type (Ballistic/standard, Melee, Explosive, Fire, Gas, Arc, Acid, Impact/fall); matching resistances multiply together before the hit is applied (e.g. Fortified −50% explosive, Inflammable −75% fire, Ballistic Padding −25% explosive and −25% torso, Vitality Enhancement −10% all, Experimental Infusion −10% while a stim is active). Servo-Assisted adds +50% arm/leg HP; Feet First stops legs breaking; Reinforced Epaulettes and Kinetic Displacement give a 50% roll for a limb to hold at 1 HP; Democracy Protects gives a 50% roll to survive a lethal hit at 1 HP; Adreno-Defibrillator revives once at 1 HP until a Long Rest. A "Last hit" line explains every reduction and roll. Effects with no sheet mechanic (reload, recoil, noise, extra stims or grenades, melee damage…) are listed as GM reference. Rules live in `PASSIVE_RULES` / `BOOSTER_RULES` in index.html; the effects panel sits under the diver image.
- Combat Overview has a Status Effects tracker with every PF2e (Remaster) condition from Player Core (checked against 2e.aonprd.com; attitudes left out since they only affect PCs through magic) grouped by type (Penalties, Death & dying, Senses, Mind, Movement & position, Detection, Persistent Damage) plus Custom. Each active condition shows a short rules summary, a value stepper for valued conditions (adding one again raises it; stepping below 1 removes it), and a notes field. Conditions save with the character and export to JSON. Their penalties are applied automatically to saves, skills, AC and attacks (never to the ability modifiers themselves), following PF2e stacking (only the worst status penalty and the worst circumstance penalty apply; those two add up): Frightened/Sickened on everything; Clumsy (and Encumbered as clumsy 1) on Dex-based rolls, AC and gun/throwable attacks; Enfeebled on Str-based rolls and melee/unarmed attacks; Drained on Con; Stupefied on Int/Wis/Cha and Will; Fatigued −1 AC and saves; Fascinated −2 skills; Unconscious and Dying −4 AC and Reflex; Broken (armor) −1/−2/−3 AC for light/medium/heavy; Drained also lowers max Main HP by level × value; Off-Guard (also from Prone, Grabbed, Restrained, Paralyzed, Unconscious, Dying, Confused) −2 circumstance to AC; Prone −2 circumstance to attacks. Penalized numbers show in red with their cause. Persistent Damage examples use Helldivers numbers (100 fire, 25 gas). The "Other modifier" inputs for AC and attacks were removed.
- A Combat Overview follows Inventory / Loadout; attack names follow the selected loadout. Modifier calculations are deferred to a later step. Overview values save with the character and export to JSON.
- Combat Overview tracks Main (125), Head (85), Torso (60), Arms (35), and Legs (45) HP. A hit removes the entered amount from that body part, then applies its location factor to Main HP (Head 150%, Torso/Chest 100%, Arms and Legs 85%; rounded to nearest HP). Arms and legs become Broken at 0 HP. Main HP at 0 displays a black visor bar and Deceased notice. Stim restores all HP and turns Broken limbs to Injured; Short Rest restores half missing HP to Main and unbroken parts; Long Rest restores all HP and advances broken/injured limbs by one recovery stage. The segmented body display turns red in proportion to damage, and HP/injury state persists and exports with the character.
- The damage display uses the supplied Helldiver reference images as its body artwork and transparent zone overlays, tinting damaged zones red and switching Injured limb overlays to orange, including when their HP is fully restored.
- An expandable level guide appears above the character details, with setting-friendly benchmarks for levels 1, 2, 3, 4–5, 6–8, and 9.
- Appearance can be switched using the three-stop control in the top right. Loyalist uses muted gray-blue surfaces, dark navy controls, and light-blue highlights; Dissident uses high-contrast black and red; Merc keeps field olive/slate/brass. The selection is saved with the character. Dissident and Merc remain roleplay interpretations rather than official named palettes.
